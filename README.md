# filing-ontology

기업 공시보고서에서 회사 사이의 관계를 뽑아 온톨로지(지식 그래프)로 만드는 프로젝트입니다.

> **상태(2026-11-13): 시작 단계입니다. 아직 구현된 기능이 없습니다.**
> 아래 내용은 초안이며, 만들면서 고칩니다.
> 자세한 구상과 아직 못 정한 것은 [docs/concept.md](docs/concept.md)에, 다음 방향(투자형 메이븐)은 [docs/investment-maven.md](docs/investment-maven.md)에 있습니다.

## 풀려는 문제 (초안)

한 회사가 누구에게 팔고, 누구에게서 사고, 누구와 경쟁하는지는 공시에 적혀 있습니다.
하지만 회사마다 수백 쪽짜리 문서에 흩어져 있어서, "이 회사가 흔들리면 누가 영향을 받는가"를 알려면 여러 회사의 공시를 직접 읽고 이어 붙여야 합니다.

## 가설

- 공시에 적힌 관계(주요 고객, 공급사, 경쟁사, 사업 부문, 리스크)를 정해진 틀로 뽑아 그래프로 이으면, 위 질문에 문서를 다시 읽지 않고 답할 수 있다.
- 검증 방법: 아직 정하지 않았습니다.

## 첫 범위 (검토 중)

| 항목 | 안 |
|---|---|
| 데이터 | 미국 SEC EDGAR의 분기보고서(10-Q). 10-Q를 내지 않는 회사는 그 회사의 정기 공시(네비우스는 6-K, 20-F) |
| 대상 | 코어위브(CoreWeave, CRWV)부터 시작. 네비우스(NBIS) → 아이렌(IREN) → 엔비디아(NVDA) → 고객사 순으로 넓힘 |
| 첫 문서 | [2026년 3분기 10-Q](https://www.sec.gov/Archives/edgar/data/1769628/000176962826000465/crwv-20260930.htm) (2026-11-12 제출) |
| 뽑을 관계 | 고객, 공급사, 경쟁사, 사업 부문, 리스크. 문서를 읽은 뒤 확정 |

한 회사의 문서 한 건에서 온톨로지가 제대로 나오는지 먼저 확인하고, 그다음에 분기와 회사를 늘립니다.

## 돌려 보기

파이썬 3.12, 표준 라이브러리만 씁니다.

SEC는 공시 본문을 연락처를 밝힌 프로그램에만 줍니다. 레포 맨 위에 `.env` 파일을 만들고 한 줄을 넣습니다(이 파일은 커밋되지 않습니다).

```
SEC_USER_AGENT=research-script/0.1 you@example.com
```

```bash
python scripts/fetch_sec.py        # SEC에서 공시 목록과 구조화 재무 데이터를 받는다 (data/raw/, 커밋 안 함)
python scripts/build_values.py     # 분기별 지표 값을 만든다 (ontology/values_xbrl.json)
python scripts/merge_text.py       # 글에서 뽑은 값을 검토 규칙으로 걸러 옮긴다 (ontology/values_text.json, relations.json)
python scripts/check_quotes.py ontology/values_text.json ontology/relations.json   # 근거 문장이 원문과 글자 그대로 맞는지 검사
python scripts/build_dashboard.py  # 대시보드가 읽는 dashboard/data.js를 만든다
python scripts/loop.py             # 감시 조건에 걸린 변화를 알림으로 만든다 (ontology/alerts.json)
python scripts/thesis.py           # 가설의 조건을 최신 값에 비춰 판정한다 (ontology/judgments.json)
python scripts/replay.py           # 지난 분기로 되돌아가 고리를 한 바퀴 돌려 본다 (시연용, 아무것도 저장하지 않는다)
python scripts/serve.py            # http://localhost:8765 에서 본다. 화면에서 한 행동(검토, 정정, 잇기, 조건 판정, 판단, 돌아보기)을 기록한다
```

지금 되는 것

- 네비우스, 코어위브, 아이렌, 엔비디아 네 회사를 한 화면에서 비교합니다.
- 지표 아홉 개: 매출, 전년 대비 성장률, 영업이익, 설비투자, 수주 잔고, 현금, 계약 전력, 가동 전력, 최대 고객 비중.
- 숫자마다 근거 공시가 붙고, 글에서 뽑은 값은 원문 문장이 함께 나옵니다.
- 엔비디아가 세 회사에 GPU를 공급한다는 관계와 그 근거 문장.
- 화면은 두 종류입니다. 고정 화면(지표 비교)과 질의 화면(질문 하나에 맞춘 화면, `views/*.json`으로 정의). 첫 질의 화면은 "네비우스가 분기마다 가격에 대해 한 말"입니다.
- 고리: 감시 조건에 걸린 변화가 "알림" 탭에 뜨고, 화면에서 검토함 표시·값 정정·가려진 고객 잇기를 하면 `ontology/actions.jsonl`에 기록되어 다음 화면에 반영됩니다(구상 문서 16장).
- 가설: `ontology/theses.json`에 적은 가설의 조건을 최신 분기 값에 비춰 "가설" 탭에 지켜짐, 가까워짐, 반대로 움직임, 깨짐, 판정 불가로 보여 줍니다. 지켜지지 않거나 앞 분기와 판정이 달라진 조건은 "알림" 탭 맨 위에 뜹니다. 발언에 기대는 조건은 사람이 읽고 판정을 기록합니다.
  - 지금 판정하는 가설은 하나입니다: 네비우스 "팔수록 더 남는다"의 조건 "조정 EBITDA 마진이 좋아진다". 나머지 가설 둘과 조건 둘은 `"paused": true`로 보류해 두었습니다. 자세한 내용은 [docs/investment-maven.md](docs/investment-maven.md) 5-1장에 있습니다.
- 판단과 돌아보기: 가설마다 무엇을 하기로 했는지와 이유를 적으면 그때의 가설 모습과 함께 기록됩니다. 그 뒤에 새 분기가 들어오면 "돌아볼 때"로 표시됩니다. 시스템은 무엇을 할지 말하지 않습니다.
- 값이 없는 칸은 이유를 적습니다: 아직 안 읽음, 공시에 없음(사람이 원문을 확인하고 `ontology/absences.json`에 적은 것만), 해당 없음.
- 계산 지표: 영업이익률처럼 다른 지표에서 계산하는 지표는 `ontology/metrics.json`의 `derive`에 적습니다.

아직 안 되는 것

- 글에서 값을 뽑는 일은 코드가 아니라 언어 모델이 대화 중에 했습니다(`data/work/`, 커밋 안 함). 다시 돌리는 코드는 없습니다.
- 새 공시가 나오면 자동으로 반영하는 기능.
- 고객사, 그리고 공급 말고 다른 관계.
